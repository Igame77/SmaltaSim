# Vkm.ComplexSim — PyGame аналог симулятора станций РЭБ

Кроссплатформенный аналог тренажера-симулятора станций радиоэлектронной борьбы и радиолокации (**ЛО01 «Смальта»** и **Импульсная РЛС ОНЦ**), разработанный на **Python** с использованием библиотеки **PyGame-CE**.

---

## Возможности

1. **Точная визуальная и масштабная копия оригинального C# WPF тренажера**:
   * Разрешение холста 1600×800 со всеми аутентичными фоновыми изображениями панелей.
   * Спрайты тумблеров, кнопок, галетных переключателей, потенциометров, индикаторных ламп и световых табло (транспарантов).
   * Реализация экрана кругового обзора РЛС с отметками целей и подавлением прямошумовой/ЧМШ помехой.
   * Реализация осциллографа С1-65 с координатной сеткой, люминофорным лучом и режимами развертки.
   * Реализация цифрового генератора импульсов Г5-15.
2. **Все приборы и органы управления**:
   * **Изделие ЛО01 «Смальта»**: блоки `ЛО01-П`, `ЛО01-Р`, `ЛО01-И + ЛО01-К`.
   * **Импульсная РЛС ОНЦ**: панели `Радиолокационная станция`, `Пульт управления имитатора`, `Генератор импульсов Г5-15`, `Осциллограф С1-65`, `Экран индикатора`.
3. **Режимы работы**:
   * **Обучение (Training)**: адаптивная 3-уровневая система непрямых подсказок:
     1. **Уровень 1 (Задача)**: формулируется цель действия (например, *«Запустите систему: подайте накал и начните прогрев радиоаппаратуры...»*) без прямого указания конкретного тумблера/кнопки, развивая самостоятельное мышление курсанта.
     2. **Уровень 2 (Уточнение)**: при ошибочном действии (нажатии не того тумблера) подсказка автоматически детализируется с указанием блока/панели и функциональной группы органов управления.
     3. **Уровень 3 (Прямое указание)**: при повторном затруднении или по нажатию клавиши `F1` / кнопки `Уточнить` симулятор переходит к прямому наведению с неоновой подсветкой нужного органа управления и всплывающей стрелкой.
   * **Экзамен (Examine)**: автономная работа с фиксацией действий курсанта, расчетом процента совпадения с эталоном, правильности порядка и штрафа за лишние клики (итоговая оценка от 1 до 5).
4. **Горячие клавиши**:
   * `F1` / `H`: запросить помощь / уточнить подсказку (эскалация уровня).
   * `F11` / `Alt+Enter`: полноэкранный режим.
   * `Пробел`: продолжение на информационных шагах алгоритма.
5. **Пасхалка (Easter Egg)**:
   * Ввод чит-кода `явсесдам` (на английской клавиатуре `zdctclfv`) в режиме экзамена включает режим отличника с отображением TrollFace и оценкой «Отлично (5)».

## Запуск симулятора

### Вариант 1 (через uv — рекомендуется)
```bash
cd SmaltaSimPygame
uv run python main.py
```

### Вариант 2 (через пакетный файл в Windows)
Дважды кликните по файлу `run.bat` в папке `SmaltaSimPygame`.

### Запуск тестов
```bash
uv run pytest tests/test_simulation.py -v
```
