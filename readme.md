> 🚀 **Новая версия на PyGame (флагманская редакция)**: современный автономный тренажёр-симулятор станций радиоэлектронной борьбы и радиолокации (**ЛО01 «Смальта»** и **Импульсная РЛС ОНЦ**), полностью переписанный на **Python / Pygame-CE**. ## 🎛 Моделируемое оборудование

### 1. Станция активных помех ЛО01 «Смальта»
* **Блок ЛО01-П** (Пульт управления и индикации): тумблеры питания, каналов 1-6, антенны, эквивалента, переключатели режимов, кнопки включения накала и высокого напряжения.
* **Блок ЛО01-Р** (Регулировка и контроль): измерительные стрелочные приборы с плавной физической интерполяцией токов накала, катода и коллектора ЛБВ, потенциометры усиления и подстройки.
* **Блоки ЛО01-И + ЛО01-К** (Индикация и контроль): световые транспаранты режимов работы и сигналов исправности.
* **Штатные учебные алгоритмы**:
  1. *Подготовка изделия ЛО01 к включению*;
  2. *Включение изделия ЛО01*;
  3. *Выключение изделия ЛО01*.

### 2. Импульсная РЛС ОНЦ с имитатором помех
* **Пульт РЛС**: селектор дальности, тумблеры питания, накала, антенны.
* **Экран кругового обзора РЛС**: динамическая развертка, отображение истинных и ложных целей, секторы шумовой и ответно-импульсной помехи.
* **Осциллограф С1-65**: люминофорная трубка с координатной сеткой, переключатель развертки (1, 0.1, X), осциллограммы сигналов и помех.
* **Генератор импульсов Г5-15**: цифровое табло, тумблеры задержки, амплитуды и длительности импульсов.
* **Пульт имитатора**: регулировка мощности помехи, переключение видов подавления.
* **Учебный алгоритм**: *Снятие зависимости коэффициента подавления от параметров импульсов*.

## 🎯 Режимы работы

1. **Режим «Обучение» (Training)**:
   * Интерактивная пошаговая инструкция с динамической подсветкой нужных тумблеров.
   * Указатель перехода между блоками (показывает, на какой блок станции нужно переключиться).
   * Автоматическая валидация правильности каждого действия перед переходом к следующему шагу.

2. **Режим «Экзамен» (Examine)**:
   * Полная свобода действий курсанта на всех панелях станции.
   * Фиксация полной истории переключений.
   * Оценивание по оригинальной формуле военной кафедры:
     $$\text{Результат} = \text{Полнота алгоритма} \times \text{Правильность порядка} - \text{Штраф за лишние действия}$$
   * Выставление официальной академической оценки: **5 («Отлично»)**, **4 («Хорошо»)**, **3 («Удовлетворительно»)**, **2 («Неудовлетворительно»)**.

3. **Секретный режим (Easter Egg)**:
   * Чит-код `явсесдам` (в раскладке `zdctclfv`) для демонстрационного включения режима отличника.

## 💻 Запуск из исходного кода

### Способ 1: С использованием `uv` (рекомендуется)
```bash
cd SmaltaSimPygame
uv run python main.py
```

### Способ 2: Через стандартный `pip` и виртуальное окружение
```bash
cd SmaltaSimPygame
python -m venv .venv
# Активация на Windows:
.venv\Scripts\activate
pip install -r requirements.txt # или pip install pygame-ce pytest pyinstaller
python main.py
```

### Способ 3: Быстрый запуск на Windows
Просто запустите файл `SmaltaSimPygame/run.bat` двойным кликом мыши.

## 🧪 Запуск автоматических тестов

Проект оснащен набором юнит- и интеграционных тестов, проверяющих физику тумблеров, зависимости реле, алгоритмы подготовки станций и математику экзаменатора:

```bash
cd SmaltaSimPygame
uv run pytest tests/test_simulation.py -v
```

## 📦 Сборка собственного `.exe` файла

Для компиляции автономного Windows-приложения используется готовый скрипт:

```bash
cd SmaltaSimPygame
uv run python build_release.py
```

Скрипт автоматически:
1. Запустит PyInstaller с иконкой `logo.ico` и корректным включением ресурсов.
2. Соберет директорию `dist/SmaltaSim/SmaltaSim.exe`.
3. Упакует релиз в архив `dist/SmaltaSim-v2.0.0-windows-x64.zip`.
